
# Jeu RPG textuel — Projet académique

Jeu de rôle textuel développé en Python dans le cadre d'un projet académique réalisé en équipe. Le joueur crée un personnage, explore un univers et affronte des monstres directement depuis le terminal.

## Fonctionnalités

- Création de personnage : Warrior, Mage ou Archer.
- Gestion des statistiques : points de vie, force, niveau et expérience.
- Navigation dans le jeu à partir de choix saisis au clavier.
- Gestion de l'inventaire, des armes et des potions.
- Combats contre des monstres.
- Progression et récompenses.

## Technologies et outils

- **Langage :** Python.
- **Bibliothèque :** Random.
- **Environnement :** Terminal / Console.

## Notions de programmation utilisées

- Fonctions Python.
- Classes et objets.
- Conditions et boucles.
- Génération de valeurs aléatoires.
- Gestion des interactions utilisateur avec `input()` et `print()`.

## Organisation du projet

Le fichier principal `Jeux_RPG.py` orchestre le déroulement du jeu et utilise plusieurs modules dédiés aux joueurs, monstres, armes, potions, inventaire, menu et combats.

## Installation et lancement

### Prérequis

- Python 3 installé sur votre ordinateur.

### Lancement

Cloner le dépôt :

```bash
git clone URL_DU_DEPOT
```

Accéder au dossier :

```bash
cd NOM_DU_PROJET
```

Lancer le jeu :

```bash
python3 Jeux_RPG.py
```

Le jeu se déroule directement dans le terminal. Suivez les instructions affichées et saisissez les choix correspondants.
